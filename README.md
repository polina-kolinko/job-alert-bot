# job-alert-bot

Telegram-бот для поиска и отслеживания вакансий через открытый API «Работы России».

Бот умеет искать вакансии по обычному текстовому запросу, сохранять подписки пользователя и периодически проверять, появились ли новые вакансии по этим запросам. Чтобы не отправлять одно и то же несколько раз, ID уже отправленных вакансий сохраняются в SQLite.

Для работы с Telegram используется aiogram, запросы к API выполняются асинхронно через httpx, база данных работает через aiosqlite. Токен бота хранится в `.env` и не попадает в репозиторий.

Основные команды:

`/start` — запуск бота  
`/subscribe python` — добавить подписку  
`/subscriptions` — посмотреть свои подписки  
`/unsubscribe python` — удалить подписку  

Также можно просто отправить боту текст, например `python` или `sql`, и он сразу вернёт несколько найденных вакансий.

При запуске проекта автоматически создаётся локальная база `job_alert.db`. В ней хранятся подписки пользователей и вакансии, которые уже были отправлены.

Для запуска нужно установить зависимости из `requirements.txt`, создать файл `.env` с переменной

`BOT_TOKEN=your_telegram_bot_token`

и запустить проект командой

`python -m app.telegram_bot`
